# AI 生成的玩家器械姿势（char_worker_*）

玩家角色（白衬衫挽袖、黑西裤、黑皮鞋、棕色短乱发，Q 版）使用 4 种器械的姿势帧。
全部为横向条带：每帧一格、格子等宽、从左到右为第 0..N-1 帧；透明背景，alpha 只有 0/255，无抗锯齿。
颜色量化到 `tools/art/palette.json` 的子集（`build_gym_poses.py` 里的 `WORKER_SUBPALETTE`，约 10 色），1px 深色描边 `#3a3a50`。

由 `tools/art/build_gym_poses.py` 从 `assets/generated/_raw/` 的 AI 原图生成（原图不进仓库），提示词见 `assets/generated/_prompts/`。

## 锚点约定

锚点 `(x, y)` 是格内像素坐标（原点为格左上角）：

- 站姿 / 侧面：`y` 是**地面线**，角色最低的不透明像素（鞋底）在第 `y-1` 行；`x` 是参考点所在列。
  在 Godot 里用 `Sprite2D`，设 `centered = false`、`offset = -anchor`，节点位置即脚底点。
- 卧推（俯视躺姿）：同样以脚底中心对齐（双腿左右对称，脚中心即身体中轴），另给出身体中心供摆到凳子上时参考。

## 附加尺寸：`tall/`（与 LimeZu 行走图同比例）

`assets/sheets/characters/npc_walk_set*_48.png` 实际是 **48×96 的格子、人物约 64–66px 高、脚踩在格子最底行**。
48 格版本（42px）放在这些 NPC 旁边会明显矮一截，所以同一批姿势另出了一套同比例版本，文件名相同：

## 已知不足

- 卧推的"举高"在俯视下只能靠杠铃位置区分（杠在脸前 vs 杠在胸腹），手臂伸直不明显；推举动画建议再用 Tween 让两帧之间平滑移动。
- 各帧由 AI 分别生成，发型细节、衬衫褶皱逐帧略有差异；已按头宽 / 身高归一化并对齐锚点，播放时不抖，但细看会有细节跳变。
- 跑步 4 帧中 1、3 两帧（腾空交叉）比较相似。
