# Ultimate Gym Championship（Demo）

打工人的潜行日常。开始界面有两个关卡：

- **Demo：办公室**：干完今天的活、偷偷在前台签退、坐电梯提前下班，别被产品经理、同事和前台发现。
- **健身房**：午休 3 分钟，把今天的训练量练完，和常客抢器械，还不能被巡视的产品经理抓去开需求会。

Godot 4.7 · GDScript · 像素风 960×540

## 怎么玩

- 双击 `play.bat`（默认用 Steam 版 Godot 路径；别的路径先设环境变量 `GODOT_EXE`），或者用 Godot 编辑器打开本目录按 F5。
- 开始界面用鼠标点，或 ← → 选、E 确认（也可以直接按 1 / 2）；进关卡后按 **E** 开始。暂停或结算时按 **M** 回菜单。

### 办公室（2 分钟）

按顺序完成四件事，全部完成即胜利：

| 任务 | 玩法 |
|---|---|
| 工位敲完代码 | ← → 交替敲键盘 14 次 |
| 打印周报 | 纸快出来（指针进绿区）时按 E，接 4 张 |
| 前台签退 | 按住 E 签名，绿区松开；要趁前台低头看电脑时签 |
| 坐电梯 | 按住 E 按电梯，松手进电梯 |

- 同事大多盯着屏幕（视野很短），会时不时转头看过道；前台轮流看电脑、抬头、看电梯口。
- 书架、打印机、饮水机挡视线；会议室是玻璃的，挡路不挡视线。办公室里站着不动也很显眼。
- 被发现：送回工位、扣 15 秒，3 次出局。做完的任务不能重复做。

### 健身房（3 分钟）

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（默认慢走，比较安静） |
| Shift | 跑（快，但更容易被发现） |
| E / 空格 | 上器械、做动作；器械被占时排队，排第一且对方上器械超过 3 秒可以挤开 |
| F | 放下 / 拿起水杯：放在器械旁就占住它，常客不会来抢 |
| Q | 离开器械 |
| Esc | 暂停 |
| R | 重开 |

**四个动作**

| 器械 | 玩法 | 收益 |
|---|---|---|
| 卧推 | 按住 E 蓄力，在绿区松开，5 次一组 | 力量 +4 |
| 哑铃弯举 | ← → 交替按，6 次一组 | 力量 +3 |
| 跑步机（2 台） | 连按 E，把速度维持在绿区 | 耐力 +4 |
| 沙袋 | 沙袋荡回来、指针进绿区时按 E | 爆发 +3 |

- 训练量满 100%（36 点）即胜利；每完成一组获得 8 秒"隐身"（被发现速度 -40%）。
- 六个健身房常客会抢器械，每台器械最多排 3 个人。排队时混在人群里不显眼（算作掩护）。排第一时可以按 E 挤开正在用的人（对方上去超过 3 秒），但会很吵，产品经理会转头看过来。
- 水杯：放在一台器械旁边就占住它，常客不会去排；轮到你直接上。拿起水杯就解除占位。
- 产品经理按固定路线走，每到一个点停下左右扫视。被黄色视野照到，警戒条上涨；满了被抓回门口、扣 15 秒，第 3 次被抓本局结束。
- 柜子、柱子挡视线，旁边的浅绿色区域是掩护点，躲在里面警戒涨得慢、退得快。在器械上训练时更显眼。
- 结算评级：S（零被抓且用时 ≤ 108 秒）/ A（零被抓）/ B / C / D。

## 开发

```powershell
powershell -File tools/test.ps1                 # 全部测试（55 个），有任何脚本错误也算失败
powershell -File tools/shot.ps1 out.png --autostart --autoplay --shot-frames=600   # 截图
powershell -File tools/godot.ps1 --import       # 刷新导入/类缓存
```

- `scripts/`：`core`（autoload、主场景、音效、自动游玩机器人）、`stations`（器械与小游戏）、`actors`（玩家、常客）、`stealth`（视野、巡逻、警戒）、`level`、`ui`
- `data/stations/*.tres`：每种器械一份数据；新增器械只加 `.tres` 和美术，不改代码
- 设计文档：`docs/DEMO_SCOPE.md`（本 Demo 范围）、`docs/PLAN.md`、`docs/OPUS_BRIEF.md`；进度见 `docs/STATUS.md`
- 美术：玩家的四个动作姿势是 AI 生成（Codex），流水线在 `tools/art/`，说明见 `assets/characters/generated/README.md`

## 素材与鸣谢

- 室内、器械与角色原画：**LimeZu — Modern Interiors**（https://limezu.itch.io/moderninteriors），付费素材，按其授权要求署名。原素材**不在仓库里**（见 `.gitignore`），没有这些文件时游戏会自动改用色块占位，照样能玩。
- 角色的健身动作图：以 LimeZu 角色为参考，由 AI（Codex）绘制后按原素材的 16px×3 像素网格和调色板处理，属于本项目的衍生素材。
- 音效与 BGM：代码实时合成。
