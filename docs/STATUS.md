## 验证

- `tools/test.ps1`：36 个测试全过，覆盖占用原子性、1000 次随机操作不变量、每个 `.tres` 都能完成一组、小游戏规则、5 分钟 NPC 模拟、可达性、视野遮挡与边界、警戒速率、被抓流程、20 次重开无残留、整局可通关。
- 变异检查：故意改坏占用释放、掩护系数，测试都能抓到。
- 干净克隆（没有授权素材）测试全过，画面自动用色块。
- 自动机器人：无巡逻时约 69 秒通关；有巡逻、完全不躲视野时 131 秒内被抓 3 次（训练 80%）。会躲的人类玩家应能拿 A/S。

## 已知问题和取舍

- 卧推两帧主要靠杠铃高低区分，玩家那两帧比较接近；靠蓄力条辅助表达。
- 跑步机是背面跑步，没有上下起伏；红衣常客的出拳架势双腿交叉，略怪。

- 未导出 exe：本机没有 Godot 导出模板（约 1 GB，需要下载许可）。目前用 `play.bat` 启动。
- 推送到 GitHub 需要 Git Credential Manager 登录一次（弹窗），之后才能 push。
